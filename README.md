In C#, There are different types of variables (Defined with different keywords).
1. Integer (4 Bytes) :
     int age = 17;
2. Long (8 Bytes) :
     long num = 9223372036854775807;
3. Float (4 Bytes) :
     float Pi = 3.14f;
4. Double (8 Bytes) :
     double num2 = 2.1283833838939;
5. Boolean (1 Byte) :
     bool Rain = true;
6. Character (2 Bytes) :
     char letter = 'C';
7. String (2 Bytes Per Character) :
     string name = "Chaitanya Kasved";
